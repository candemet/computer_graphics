    Datastructuren

• Pas de bestaande datastructuren aan om Z-Buffering met
  lijnen te ondersteunen:
  – Voor Z-buffering met lijnen zijn de originele Z-coördinaten van de
    geprojecteerde punten nodig. Deze moeten dus mee worden
    opgeslagen in het Line2D Object:

   class Line2D {
    public:
      Point2D p1;
      Point2D p2;
      Color color;
   };
      double z1;                     Deze velden moeten worden
      double z2;                     ingevuld tijdens het projecteren
   };

    typedef std::list<Line2D> Lines2D;

     Datastructuren

• Maak een datastructuur aan om de ‘ZBuffer’ in bij te
  houden:
   – De Z-buffer houdt voor elke pixel de kleinste 1/z waarde bij
   – Voor elke pixel wordt de 1/z waarde op +∞ geïnitialiseerd
   – Stel zelf een zinvolle datastructuur op, of baseer je op de gegeven
     datastructuur
      • De gegeven code dient enkel als voorbeeld. Het kan nuttig zijn om,
        daar waar nodig, de nodige abstracties in te voeren

    class ZBuffer: public std::vector<std::vector<double> >
    {
       public:
        //Constructor: maakt een Z-Buffer van de correcte
        //grootte aan en initialiseert alle velden op +inf
        ZBuffer(const int width, const int height);
    };

    Z-buffering met lijnen

• Tips:

  – De verschillende elementen van je Zbuffer moeten op +∞ worden
    geïnitialiseerd. Deze waarde kan door een double worden
    voorgesteld. Om deze waarde op te vragen kun je gebruik maken
    van onderstaande code.
          double posInf = std::numeric_limits<double>::infinity();
          double negInf = -std::numeric_limits<double>::infinity();

    Je moet hiervoor wel de <limits> header includen.
